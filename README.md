# Crime Data Analysis Dashboard

## Project Overview

This project presents an interactive Crime Data Analysis Dashboard developed using Microsoft Excel. The dashboard transforms raw crime data into meaningful visualizations and insights to analyze crime patterns across different states, districts, years, and crime types.

## Objective

The objective of this project is to analyze crime-related data and identify trends and patterns in reported cases, chargesheeted cases, convictions, and crime rates.

## Tools and Skills

* Microsoft Excel
* Data Cleaning and Preparation
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Functions
* Data Visualization
* Dashboard Development

## Dashboard Features

* Interactive KPI cards
* Crime trend analysis
* Crime type analysis
* State and district-level analysis
* Chargesheeted and conviction analysis
* Interactive slicers for filtering
* Multiple charts for data comparison
* Interactive dashboard layout

## Key Insights

The dashboard provides an overview of crime patterns and trends across different time periods and geographical regions. It helps identify variations in reported cases, crime types, chargesheet rates, conviction rates, and crime rates.
